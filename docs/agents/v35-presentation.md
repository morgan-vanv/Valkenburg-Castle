3. **Parley card (18.6):** the `parley` action opens a card: crew name, temperament, stance, members, what they're after (`aim`: what, rounds, value), each deal from `deals()` with price, `pays`, `risk`, `blocked`; job sub-choices; Fight as a clear button. Hired crews read as allies (green ring/tag), hostile as enemies.
4. **Models:** rival Sellsword (shield), Sapper (hammer, charge), Pyromancer (staff, flame) in each crew's colours (Ferrymen: river blue-grey; Gallows Choir: black and bone); intents `toll`, `charge` (blast hexes), `firebolt` (line) drawn like the others. The heavy copper as a ground-loot model if cheap; otherwise a generic heavy sack is fine.
5. **Tooltips and help** for everything new, in the V3.4 style (names.ts, live numbers).
